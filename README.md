# Nuestra historia

Álbum personal construido con React, Vite y Motion.

Requisitos: Node.js 20.19+ o 22.12+ y npm.

```sh
npm install
npm run dev
npm run build
npm run preview
```

La compilación se genera en `dist/`. Los recuerdos se editan en `src/memories.json`, y las imágenes y videos originales se encuentran en `resources/`. Los reproductores requieren conexión a Spotify.
